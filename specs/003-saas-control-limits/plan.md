# Implementation Plan: SaaS Control Tower & Iron Wall

**Branch**: `003-saas-control-limits` | **Date**: 2026-02-25 | **Spec**: [spec.md](./spec.md)

## Summary

Implement role-based navigation isolation (SUPER_ADMIN Control Tower), subscription plan limit enforcement (Iron Wall), subscription lifecycle banners and grace-period enforcement, tenant-to-license DRM binding with suspension cascade, and an offline JWT time-bomb for the Electron desktop app.

## Technical Context

**Language/Version**: TypeScript 5.3+ (all apps)
**Primary Dependencies**: Next.js 14 App Router, Prisma 5.x, React 18, TailwindCSS v3.4, Lucide React, Electron 28, NextAuth v5, jose (JWT signing/verification for offline tokens)
**Storage**: PostgreSQL via Prisma (web/cloud); SQLite via Prisma (desktop); Electron secure store (offline token)
**Testing**: Not requested
**Target Platform**: Web (`apps/web`) for Parts A–D; Desktop (`apps/desktop`) for Part E
**Project Type**: Multi-tenant SaaS web app + Electron desktop app (monorepo)
**Performance Goals**: Subscription state check adds < 5ms to each authenticated request
**Constraints**: Offline-capable enforcement on desktop; zero new public API endpoints for control tower; pnpm workspace throughout
**Scale/Scope**: Affects all authenticated routes in `apps/web`; all startup/wake events in `apps/desktop`
