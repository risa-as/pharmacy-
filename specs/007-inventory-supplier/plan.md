# Implementation Plan: Supplier Selection in Inventory Management

**Branch**: `007-inventory-supplier` | **Date**: 2026-03-04 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/007-inventory-supplier/spec.md`

## Summary

Add an optional supplier selection field to all inventory stock-entry forms across the web dashboard, mobile app, and desktop app. The `Batch` model (which represents a physical stock shipment) gains an optional `supplierId` FK in both the cloud PostgreSQL schema and the local desktop SQLite schema. A lightweight `Supplier` cache table is added to the desktop schema for offline dropdown support. All three apps' UI forms (Add Batch, Quick Create Drug) receive a searchable supplier picker. Purchase order receive flows automatically inherit the supplier from the parent purchase — no UI change there.

## Technical Context

**Language/Version**: TypeScript 5.3+ (all apps)
**Primary Dependencies**: Next.js (App Router), Expo (React Native + NativeWind), Electron + React, Prisma ORM

**Testing**: Manual QA per quickstart.md (no automated tests requested for this feature)

**Project Type**: Multi-platform pharmacy management system (monorepo)
**Performance Goals**: Supplier dropdown must filter within 300ms; no new latency on batch save
**Constraints**: Desktop must work fully offline; pnpm only; no cross-app imports
**Scale/Scope**: ~3-5 forms across 3 apps; ~2 DB schema changes; ~3 API route modifications
