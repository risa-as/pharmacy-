# Implementation Plan: Global UI & Dark Mode Standardization

**Branch**: `002-ui-standardization` | **Date**: 2026-02-23 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `specs/002-ui-standardization/spec.md`

## Summary

Perform a systematic, file-by-file migration of every hardcoded Tailwind color class across
the web dashboard and desktop app to semantic CSS variable tokens. Apply the `glass-card`
visual effect to all web dashboard list/detail pages. Add named CSS custom properties for
inline hex gradients. No new dependencies, no new components, no API changes — pure
class-name and CSS-property substitutions.

The token infrastructure is 100% complete from Phase 1 (T001–T034):
`packages/shared/tailwind.config.ts` defines all tokens; `globals.css` and `index.css`
define all CSS variables and the `.glass-card` utility. This phase is the application
of that infrastructure to every file that was not migrated in Phase 1.

---

## Technical Context

**Language/Version**: TypeScript 5.3+ (all apps)
**Primary Dependencies**: TailwindCSS v3.4 — all tokens already in `packages/shared`;
no new dependencies needed
**Storage**: N/A — no storage changes
**Testing**: Visual inspection per Definition of Done checklist (grep + browser walkthrough);
no automated tests required
**Target Platform**: Web (Next.js, Chromium), Desktop (Electron renderer, Chromium)
**Project Type**: UI styling migration — class-name substitution only
**Performance Goals**: Dark mode toggle < 100ms (CSS class swap only; no re-render)
**Constraints**: No inline `style={{}}` for any color value (Constitution Principle VI);
`@media print` blocks exempt from migration
**Scale/Scope**: ~15 high-priority files + ~90 web dashboard pages for glass-card application
