# بيانات العرض: «صيدلية التفوق» و«مذخر التفوق»

بيانات وهمية كاملة لالتقاط صور الموقع التعريفي وللعروض التوضيحية. كل الأسماء والهواتف والبريد وهمية
(نطاق `.test`)، ولا شيء منها مأخوذ من حساب عميل.

## ماذا تنشئ

- **صيدلية التفوق** (باقة «مؤسسات»):
  - فرعان: الرئيسي في المنصور، وفرع الكرادة؛
  - مدير وصيدلانية وكاشيران؛
  - صناديق، وثلاثة موردين أحدهم مذخر التفوق؛
  - 40 دواءً بدفعاتها، بعضها قريب الانتهاء وبعضها ناقص، ودفعة منتهية؛
  - 18 مريضاً، ومبيعات 30 يوماً بينها بيع آجل، ومصروفات، وفواتير شراء، وتنبيهات؛
  - 5 مرتجعات (بينها مرتجع كلي)، و6 تسديدات ديون تخفّض أرصدة المرضى.
- **مذخر التفوق** (بوابة كاملة):
  - مالك وموظف مبيعات؛
  - كتالوج الأدوية الأربعين بأسعار وبونص؛
  - خمس صيدليات عميلة: التفوق، وأربع صيدليات وهمية أخرى؛
  - 12 طلباً في كل المراحل: مرسل، قيد المراجعة، معروض السعر، معتمد، قيد التسليم، مسلَّم، مرفوض؛
  - سجل أحداث لكل طلب، وفواتير المذخر.

حسابات الدخول، وكلها بكلمة المرور نفسها `SEED_USER_PASSWORD`:

| الحساب | الدور |
|---|---|
| `admin@altafawuq.test` | مدير صيدلية التفوق |
| `pharmacist@altafawuq.test` | صيدلانية |
| `cashier@altafawuq.test` | كاشير الفرع الرئيسي |
| `karrada@altafawuq.test` | كاشير فرع الكرادة |
| `owner@altafawuq-wh.test` | مالك مذخر التفوق |
| `sales@altafawuq-wh.test` | مبيعات المذخر |

## التشغيل (قاعدة جديدة فارغة فقط)

من مجلد `apps/web`:

```bash
createdb faramace_demo
DATABASE_URL=postgresql://USER:PASS@HOST:PORT/faramace_demo npx prisma migrate deploy
DATABASE_URL=... npx ts-node --skip-project prisma/seed-plans.ts
DATABASE_URL=... SEED_USER_PASSWORD='<12 حرفاً على الأقل>' node prisma/demo/seed-demo.cjs
```

حمايات السكربت:

- يرفض العمل إذا لم يكن اسم القاعدة `faramace_demo`. لاسم آخر اضبط `DEMO_DATABASE_NAME` على الاسم نفسه صراحة.
- يرفض العمل إذا كانت في القاعدة أي مؤسسة.
- التواريخ نسبية إلى يوم التشغيل، فتبدو البيانات حديثة دائماً.
- الأرقام ثابتة عند كل تشغيل، لأن المولّد العشوائي بذرته ثابتة.

> **لا تشغّله على قاعدة الإنتاج.** الأدوية فيه عامة (`organizationId = null`)، فتظهر لكل الصيدليات،
> والصيدليات الأربع الإضافية ستظهر كمستأجرين حقيقيين. إدخال حساب عرض إلى النظام الحي يحتاج
> نسخة مختلفة: أدوية خاصة بالمؤسسة، ودون صيدليات إضافية.

## تشغيل النظام على قاعدة العرض لالتقاط الصور

شغّل نسخة إنتاج (`next build` ثم `next start -p 3100`) من مجلد لا يستخدمه خادم التطوير.
عطّل فيها كل اتصال خارجي، لأن `.env` يشير إلى الخدمات الحقيقية ومتغيرات البيئة تتقدم عليه:

- `DATABASE_URL`: قاعدة العرض.
- `AUTH_SECRET` و`SYNC_TOKEN_SECRET`: قيم عشوائية جديدة.
- `AUTH_URL` و`NEXT_PUBLIC_APP_URL`: `http://localhost:3100`، مع `AUTH_TRUST_HOST=true`.
- فارغة: `STRIPE_*`، `ZAINCASH_*`، `UPLOADTHING_TOKEN`، `BACKUP_SECRET_KEY`، `GOOGLE_VISION_API_KEY`،
  `PRESCRIPTION_SCAN_PROVIDER`، `AI_PROVIDER`، `GEMINI_*`، `OPENAI_API_KEY`، `UPSTASH_REDIS_REST_*`،
  `WHATSAPP_*`، `CRON_SECRET`، `OFFLINE_*`، `TPM_DEVICE_AUTH_ENABLED`.

لا توجد في بيانات العرض رموز إشعارات للهواتف (`expoPushToken`)، فلا يُرسل أي إشعار.

أدوات التقاط الصور ومعالجتها في `apps/landing/scripts/screenshots`.
