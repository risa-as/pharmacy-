# Cairo mobile font assets

Source: https://github.com/expo/google-fonts/tree/4cbb54769a92d16f7b4032aa7154cc3112c1396d/font-packages/cairo

Eight static Cairo weights (200–900), distributed under the included SIL Open Font License. These are loaded with expo-font at runtime and delivered as EAS Update assets; they are not added to the native font plugin. Text and input wrappers select the matching face and preserve icon/monospace families.
